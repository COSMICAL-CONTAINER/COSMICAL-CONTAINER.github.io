统计 __VA_ARGS__ 参数个数

发表于2024-07-19
|总字数:338|阅读时长:1分钟

可变参数宏 __VA_ARGS__ 有个著名的难题：怎么知道参数有几个？预处理器没有循环、没有计数，但利用”占位符平移”技巧可以完美解决。

技巧原理

关键在参数的错位对齐：

  • 传 3 个参数时，展开成 _PrintMacroArgCount("ignored", 1, 2, 3, 9, 8, 7, 6, 5, 4, 3, 2, 1, 0)
  • _0 吃掉 “ignored”（占位符），_1~`_3 吃掉真实参数，XX` 恰好落在 3 上
  • 传 0 个参数时，XX 落在 0 上，顺便解决了 __VA_ARGS__ 为空时的逗号问题（##__VA_ARGS__ 会吃掉多余的逗号）

应用：按参数个数生成函数名
